## Selected Work

<table>
  <tr>
    <td width="50%" valign="top">
      <h3><a href="https://github.com/YOUR_GITHUB_USERNAME/YT-Insight">YT-Insight</a></h3>
      <sub><b>CONVERSATIONAL RAG FOR YOUTUBE</b></sub>
      <br/><br/>
      Ask questions about any long-form video and receive grounded answers with <b>timestamp-based source citations</b>.
      <br/><br/>
      <b>Architecture</b><br/>
      <code>Transcript API</code> → <code>Recursive chunking</code> → <code>MiniLM-L6-v2</code> → <code>FAISS</code> → <code>Cross-encoder rerank</code> → <code>Qwen 72B</code> → <code>Streamlit</code>
      <br/><br/>
      <b>Results</b>
      <ul>
        <li>Recall@5 improved from <b>83.3% to 93.3%</b></li>
        <li><b>60% faster</b> repeat-video processing with transcript and index caching</li>
        <li>History-aware query rewriting and relevance-threshold filtering</li>
      </ul>
      <sub>LangChain · FAISS · Sentence-Transformers · Streamlit</sub>
    </td>
    <td width="50%" valign="top">
      <h3><a href="https://github.com/YOUR_GITHUB_USERNAME/FraudShield">FraudShield</a></h3>
      <sub><b>EXPLAINABLE FRAUD DETECTION</b></sub>
      <br/><br/>
      Detects fraud across <b>6.36M+ PaySim transactions</b> and explains <i>why</i> each transaction was flagged.
      <br/><br/>
      <b>Architecture</b><br/>
      <code>Preprocessing</code> → <code>SMOTE</code> → <code>LR / RF / XGBoost</code> → <code>Stratified k-fold</code> → <code>SHAP</code> → <code>Streamlit</code>
      <br/><br/>
      <b>Results</b>
      <ul>
        <li><b>98.7% recall</b> · 91.4% precision · <b>94.9% F1</b></li>
        <li><b>0.89 PR-AUC</b> on a heavily imbalanced dataset</li>
        <li>Transaction-level SHAP explanations with live risk scoring</li>
      </ul>
      <sub>XGBoost · SHAP · scikit-learn · Streamlit</sub>
    </td>
